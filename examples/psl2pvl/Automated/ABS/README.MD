# CASE Study

1-wheel and 4-wheels represents the ABS SystemC designs for which automatic transformations were done, however the verification failed

1-wheel-Alternative represents the ABS SystemC designs, where PSL assertions were automatically transformed to PVL and extensive manual work was done to make the properties verifiable while using supportive invariants and the RASI from the paper "Automated Invariant Generation for Efficient Deductive Reasoning About Embedded Systems" paper by Tasche, Herber and Huisman
